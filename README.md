# Run Arimes
Lightweight English-language endless runner PWA.

## GitHub Pages
Upload all files from this folder into the repository root. Enable Settings > Pages > Deploy from branch > main / (root). Open the published HTTPS URL in PWABuilder to create a Windows package for Microsoft Store.

## Controls
Space / Up / W / tap to jump; P to pause. Scores are stored locally. Works offline after the initial visit.

## Privacy
No accounts, advertising, analytics, or personal-data collection are built into this game.

## Store submission
Review the generated package and its capabilities before submission. Store approval is not guaranteed.
